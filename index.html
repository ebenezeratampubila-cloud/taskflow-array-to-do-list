Why use an array?

An array stores multiple task records in one ordered collection.

The array behind this app

let tasks = [];

  • ADD: tasks.push(task)
  • DISPLAY: loop through the array
  • UPDATE: change a task's completed value
  • DELETE: remove a task with splice()
  • FILTER: select tasks by completion status

Other real-world uses

Arrays are useful wherever a program manages ordered collections.

  • Student marks and class lists
  • Shopping cart items
  • Music playlists
  • Daily weather readings
  • Inventory/product lists
